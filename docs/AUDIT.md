# SpendWise Phase 1 audit

**2026-11-22 · `codex/audit-and-fixes` · reviewed at `60f2ac9`**

API writes lack a commit boundary. Registration, financial writes, and session revocation can report success while their changes roll back. The production Compose file supplies committed database and JWT credentials, and the development image build can include local environment files. Treat credential exposure as a deployment question until the actual settings and image distribution are confirmed.

## Project map and the commands that work

SpendWise is a Python REST API. The repo pins Python 3.12 via `.python-version` and locks dependencies with uv. FastAPI and Pydantic handle HTTP requests, SQLAlchemy and asyncpg use PostgreSQL 16, and Alembic owns migrations. Redis 7 backs reporting, rate limits, and Celery. Uvicorn serves development and Granian serves production. There is no frontend source in this checkout.
